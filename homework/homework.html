Reflection


I used the translate, skew, hover, scale, and rotate transformations for the stars, and noticed that the order of the transformations is of vital importance, as if you aren't careful/specific, you will have images just flying off the page before they do the other transformations you wanted them to. I noticed that with some of the animations, the length of the page would extend as they changed, such as the scale or skewing. However, other stars would fly off of the page without it extending to show them, which I found quite interesting. The expanding glow of the moon also had no effect on the size of the page itself either. I also ran into a little problem when moving the code from the original index html and ccs file so that the page would work when implemented into my sketchbook. I accidentally made copies of the link code to go home/back, which resulted in there being a button that didn’t work, covering the one that did. I was only able to figure this out due to there being a pixel difference in the buttons, allowing me to see that there was a sliver of function within the page, that was trying to hide from me. One issue I’ve been having is actually this reflection, funnily enough. Trying to write it so that it looks like a paragraph that fits to the page and doesn’t come across as a continuous line of text, is proving to be rather an issue. If this appears legible, then I have succeeded, and if you haven’t gotten this far, I sadly am aware of why.

P.S. It has fixed and I honestly don’t know why, but I have a feeling it was because I was testing it with a text which had no spaces. I feel respectively pleased and stupid.
