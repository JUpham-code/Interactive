positioning elements

Back

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Response

I found that the relative positioning felt the most useful, as it allowed the box to interact with and be modified in relation to, other elements on the page, which made it all feel much more dynamic with a flow that could be altered as necessary. However, I did find the sticky positioning the most interesting, as it was in relation to the screen whilst text was present within the body, but once the writing ceased, it clung to the body, regardless of it's position prior on the screen. I think this could be very useful as a positioning for a footer, allowing the basic links towards things such as socials to be visible, and once scrolled past, the background images could be revealed, showing seemingly hidden pictures or documentation of works, giving the user a feeling of discovery. When it comes to fixed positioning, I think one must be selective with what is chosen, as should too much be adhered to the screen, the site itself would be illegible. Nonetheless, I am planning on using or experimenting with fixed, relative, absolute, and sticky positioning in the sketchbook, as I feel I could apply fixed or sticky the footer, fixed to the nav, and relative to the body with absolute to a scenic background.
